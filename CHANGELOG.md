# Changelog
All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [v21.1.1-1.21.1] - 2026-11-14

### Fixed

- Fixed extreme lag and client freezes when looking at entities with a position far away
- Fixed excessive entity lookups and log spam when another mod gives the camera entity an abnormally large bounding box
- Fixed a crash when another mod renders entities with a camera that is not usable, such as Sable
